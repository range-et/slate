# tic-tac-toe — slate-code v0.2 reference example & CI gate

This folder is the **reference example** that gates v0.2 release per
[../../slate-code-v0.2-spec.md §7](../../slate-code-v0.2-spec.md). It is the
canonical "small program built one function at a time, leaves-up, with
human-in-the-loop iteration" demo.

## What lives here (eventually)

```
examples/tic_tac_toe/
├── README.md                    ← this file
├── tic_tac_toe.slate.json       ← the source-of-truth project
│                                  (issue #28: hand-crafted JSON)
├── tic_tac_toe.py               ← compiled output (gitignored;
│                                   regenerated by scripts/compile-example.js)
└── tests/
    ├── test_units.py            ← per-card unit tests pulled out of the
    │                              cards' `tests` field
    └── test_smoke.py            ← runs `python tic_tac_toe.py` end-to-end
```

## Card structure (target)

| Card | Kind | Depends on (`@refs`) |
|---|---|---|
| `__header__` | header | — |
| `BoardState` | class | — |
| `BoardState.__init__` | body (method, parent=`BoardState`) | `BoardState` |
| `BoardState.render` | body (method, parent=`BoardState`) | `BoardState` |
| `is_winning_line` | body | — |
| `check_winner` | body | `is_winning_line`, `BoardState` |
| `valid_moves` | body | `BoardState` |
| `apply_move` | body | `BoardState` |
| `ai_player_random` | body | `valid_moves` |
| `play_loop` | body | everything else |

Generation order under the cell-as-sandbox loop (leaves first):
1. `is_winning_line` (no `@refs`)
2. `BoardState` (class shell)
3. `BoardState.__init__`, `BoardState.render`, `valid_moves`, `apply_move`
4. `check_winner`, `ai_player_random`
5. `play_loop`

## CI

Once issue **#30** lands, CI runs:

```bash
node scripts/compile-example.js examples/tic_tac_toe/tic_tac_toe.slate.json \
  --out examples/tic_tac_toe/tic_tac_toe.py
python -m pytest examples/tic_tac_toe/tests/
python examples/tic_tac_toe/tic_tac_toe.py        # smoke run
```
